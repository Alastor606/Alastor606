## `whoami`

I'm a developer who enjoys building things that are **useful, visual and a little unusual**.

My main interests are currently focused on **music software, desktop applications, interface design and creative tools**. I like working on projects where programming is not just about making something function, but also about making it **feel right**.

> I don't want to build another project just to say that I built it.
> I want to build something I'd actually want to use.

## `Projects`

### 🎧 Yandex Music Desktop

A custom third-party desktop client for Yandex Music focused on visual customization and a better desktop experience.

**Tauri · JavaScript · HTML · CSS · Rust**

Custom backgrounds, automatic color extraction, album pinning, improved karaoke, expanded genre selection, better search and audio visualization.

---

### 🗃️ Whisper Archive

A music archive project built around the idea of keeping music that you don't want to lose.

A personal experiment in combining **music, archiving and interface design**.

**ASP.NET Core · PostgreSQL · JavaScript · HTML · CSS**
